## ⚡ Core Architecture & Engineering Highlights

* **Stateless Auth & RBAC:** Custom JWT filter chains, token validation barriers, and granular role authorization.
* **Layered Design:** Controller-Service-Repository decoupling with centralized `@ControllerAdvice` global exception handling contracts.
* **Persistence & Scaling:** Schema normalization (3NF), HikariCP connection pooling, and optimized Spring Data JPA queries.
* **DevOps & Cloud:** Multi-stage Docker builds, environment parity, and cloud deployments.
* **Interactive APM Request Tracer:** Visual request-response lifecycle simulator demonstrating client ingress to persistent SQL execution.
